Why Dice, not accuracy? Almost every voxel is healthy brain, so TN dominates and accuracy looks “perfect”. Dice ignores the empty space and only scores overlap of the tumor — that is the metric the training loop tracks (validation Dice 0.837 after two epochs on this project).

Where is TP / TN / FP / FN?

Same overlapped translucent masks. Arrows point to each confusion category on a pediatric brain slice — no extra colour highlighting on the regions.

Ground Truth + Predicted Arrows label TP · TN · FP · FN

TP — True Positive

Voxel is tumor in the ground-truth mask and the model also predicts tumor. Correct detection of the mass.

TN — True Negative

Voxel is healthy / background in the ground truth and the model predicts non-tumor. Correct healthy tissue. This class is huge in 3D MRI.

FP — False Positive

Model predicts tumor, but ground truth is background. Over-segmentation — the extra magenta blob, or the blue islands in the 3D viewer.

FN — False Negative

Ground truth is tumor, but the model misses it. Under-segmentation — clinically the costly error, because part of the mass is left unmarked.
